# Harper & Ellie Mae — Christmas Website

A premium, responsive, no-build Christmas landing page for Harper & Ellie Mae.

## Included

- Premium Christmas design with bright red, green and warm gold palette
- Four-corner entrance animation that forms the page on load
- Live countdown to the next Christmas
- Automatic Christmas hamper slideshow with previous/next controls
- Christmas-morning present-opening scenes
- Animated Santa and reindeer flight across the top
- Animated Christmas train with Santa's little helpers
- Personal letter from Santa to Harper & Ellie Mae
- Responsive mobile layout
- Reduced-motion accessibility support
- No framework, no build step

## Run locally

Just open `index.html` in a browser.

## Put it on GitHub Pages

1. Create a new GitHub repository.
2. Upload `index.html`, `styles.css` and `script.js`.
3. In the repository, open **Settings → Pages**.
4. Choose **Deploy from a branch**.
5. Select your main branch and `/ (root)`.
6. Save. GitHub will publish the site.

## Customising

- Change colours and layout in `styles.css`.
- Edit the Santa letter and page wording in `index.html`.
- The countdown in `script.js` automatically targets the next December 25.
- Replace the emoji-based visual scenes with your own licensed photography whenever you have it.

## Note

The current version deliberately uses CSS, emoji and typography rather than third-party stock photography so the repository works immediately without a separate assets folder.
